## Catalog consequence

This source complements, rather than replaces, the existing Apollo 11/Luminary 1A source chain. The AC Electronics manual establishes known MSK-1137 field semantics; 70-FM-20 establishes additional mission-specific descent comparison quantities and monitoring logic. Neither source alone supplies the missing per-field Mission-G display routing/configuration.

PHO-TN401 therefore remains a named blocked target rather than being bypassed with an inferred display reconstruction.
