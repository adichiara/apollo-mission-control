## NASA TN D-7112 — *Apollo Experience Report — Simulation of Manned Space Flight for Crew Training*

- NASA MSC, March 1973, `NASA-TN-D-7112`, `MSC-S-346`, NTRS `19730011149`.
- Primary NASA program experience report.
- Supports two identical-design LMS installations; each had a three-machine digital computer complex; one machine was assigned exclusively to onboard-guidance-computer simulation; instructor/operator console, infinity-optics display, and crew station were distinct system elements.
- Does not identify the other two machines' program/model allocation, explain retrospective four-DDP-224 evidence, or establish Apollo 13 configuration/cadence/tolerances.

## NASA/MSC corporate-author index — LMS MEP program review

- Organization: NASA Manned Spacecraft Center bibliographic control.
- Source: https://www.ibiblio.org/apollo/NARASWoverflow/CorporateIndex.pdf
- Grumman entry: `LLR-400-329` — 06-07-67 — MSC accession `67-15490` — `NAS9-1100` — *CONTRACT NAS9-1100, LMS MISSION EFFECTS PROJECTOR PROGRAM REVIEW*.
- Source class: primary NASA bibliographic-control record.
- Supports the existence, exact report number, date, accession, contract, and title of a contemporaneous Grumman LMS MEP program review.
- Does **not** expose MEP architecture, EVDE relationship, computer ownership, acceptance criteria, site effectivity, Apollo 13 applicability, or relationship to later Kollsman `NAS9-8634` work.
- Retrieval gate: open the technical report before promoting any implementation claim.

## Tomayko — *Computers in Spaceflight: The NASA Experience*

- NASA-published historical synthesis, `NASA-CR-182505`, NTRS `19880069935`, March 1988.
- Supports initial two-computer LMS allocation, 8K words common memory, later third LMS computer, and that added computer's onboard-computer simulation role.
- Authoritative secondary evidence, not configuration-controlled documentation.

## Brown & Waters — *The Lunar Module Simulator*

- *SIMULATION* 15(1), July 1970, pp. 27–29, DOI `10.1177/003754977001500110`.
- Contemporaneous technical publication supporting three-machine LMS complexes, conversion electronics, cockpit, infinity-optics visual display, and instructor console.

## Jackson — *The Lunar Module Simulator: A Personal Account of Being an Instructor*

- Albert A. Jackson, 2022, DOI `10.13140/RG.2.2.30746.56005`.
- Retrospective first-person evidence recalling four DDP-224 computers in the Houston LMS complex/room; does not resolve why this differs from NASA's three-machine LMS definition.

## Evidence boundary

Mature LMS architecture is strongly supported as three machines, with one dedicated to onboard-guidance-computer simulation. NASA historical synthesis supplies a developmental two→three-machine chronology. Jackson's retrospective four-machine room observation remains unexplained. Do not invent original two-machine workloads, spare/test roles, configuration dates, or terminology.

The newly identified `LLR-400-329` / `67-15490` MEP program review is a retrieval key only. Its title must not be used to infer visual-system architecture or machine ownership.

## Architecture use

Use recovered evidence to constrain system decomposition, not constants: computing complex, guidance-computer simulation role, conversion/interface electronics, crew station, visual system, instructor control. Do not derive causal-domain count, program ownership, update cadence, integration step, or product latency from machine count or catalog metadata.
