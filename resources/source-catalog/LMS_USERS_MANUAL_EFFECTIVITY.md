- Current retrieval path rejects full page extraction because the object is approximately 92.8 MB.

## Evidence status

The cover establishes document identity, volume, update number, and date. `Update #34` makes the surviving object a specific late-program controlled document state. It does not establish when individual procedures originated or whether they were unchanged from Apollo 13.

Do not use isolated indexed snippets to establish processor allocation, program ownership, common-memory mapping, initialization/loading workflow, peripheral routing, site configuration, or Apollo 13 effectivity.

## Required extraction order

1. document-control/front matter;
2. update/change record;
3. page-level update/revision markings;
4. site/simulator identifiers;
5. machine/program ownership;
6. initialization/loading/common-memory/peripheral procedures.

Every technical statement recovered from Update #34 must remain classified as 1971-only unless an earlier source or the preserved change history establishes earlier effectivity.

## Apollo 13 gate

No Update #34 technical procedure is Apollo-13-applicable merely because it describes the LMS. Apollo-13 applicability requires period corroboration or change-history evidence showing the procedure/configuration was already effective by April 1970.
