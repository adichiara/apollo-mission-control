# Primary Source Catalog

Initial catalog established 2026-09-11.

This is not yet exhaustive. It prioritizes sources needed to reconstruct Mission Control organization, displays, rules, mission chronology, and simulation/training.

---

## MCC / flight control

### MCC Display Formats Manual

- **Title:** Display Formats Manual
- **Author:** R. L. Runnels, Philco-Ford Corporation
- **NASA document ID:** 19730010501
- **Report:** PHO-TR515 / NASA-CR-128843
- **Date:** 1973-01-12
- **Source:** NASA Technical Reports Server
- **URL:** https://ntrs.nasa.gov/citations/19730010501
- **Status:** IDENTIFIED
- **Use:** Standards, procedures, fundamentals, and constraints for operational MCC display-format design; primary starting point for display reconstruction.
- **Caution:** Published after Apollo 11. Determine which contents describe the Apollo-era system applicable to each target mission.

### Apollo 11 Flight Operations Reunion / Manning List

- **Title:** Flight Operations reunion for the Apollo 11 20th anniversary of the first manned lunar landing
- **NASA document ID:** 19910008862
- **Report:** NASA-TM-103373
- **Date:** 1989
- **Source:** NASA Technical Reports Server
- **URL:** https://ntrs.nasa.gov/citations/19910008862
- **Status:** IDENTIFIED
- **Use:** Includes official Apollo 11 flight-control manning list and flight-control historical material.
- **Caution:** Retrospective source; use contemporary mission documents where available for operational specifics.

### Apollo Mission Control organization overview

- **Source identified:** NASA Apollo-era mission documentation describing MCC as receiving tracking/telemetry from the Manned Space Flight Network, processing it through the Real-Time Computer Complex, and displaying it to controllers in the MOCR and adjacent staff-support rooms.
- **NTRS PDF surfaced in research:** https://ntrs.nasa.gov/api/citations/19760066779/downloads/19760066779.pdf
- **Status:** IDENTIFIED
- **Use:** High-level organization; states three basic MOCR operations groups: mission command/control, systems operations, and flight dynamics.
- **Action:** Identify exact document title/report metadata before citing it as an implementation source.

## Apollo 11 mission-specific sources

### Apollo 11 Flight Mission Rules

- **Title:** Apollo Flight Mission Rules, AS-506/107/LM-5, Apollo 11
- **Date represented:** 1969-04-16
- **Source:** NASA / Apollo Lunar Surface Journal archive
- **URL:** https://www.nasa.gov/wp-content/uploads/static/history/alsj/a11/a11missionrules.pdf
- **Status:** IDENTIFIED
- **Use:** Mission decision criteria, responsibilities, operational constraints, abort/alternate-mission rules, mission-specific rule organization.
- **Note:** Preface states the rules were to receive extensive evaluation during premission simulations.

### Apollo 11 Flight Plan

- **Title:** Apollo 11 Flight Plan, AS-506, CSM-107/LM-5
- **Final version date:** 1969-07-01
- **Prepared by:** Flight Planning Branch, Flight Crew Support Division
- **Source:** NASA / Apollo Lunar Surface Journal archive
- **Index URL:** https://www.nasa.gov/wp-content/uploads/static/history/alsj/a11/a11-fltplan.html
- **Status:** IDENTIFIED
- **Use:** Nominal mission timeline, spacecraft activities, updates, detailed objectives, consumables analysis.
- **Note:** NASA archive provides preliminary and final versions; exact version must be recorded when extracting implementation data.

### Apollo 11 Lunar Surface Journal — flight-plan excerpts

- **Source:** NASA
- **URL:** https://www.nasa.gov/wp-content/uploads/static/history/alsj/a11/plans11.html
- **Status:** IDENTIFIED
- **Use:** Convenient page-level access to LM activation, undocking, DOI, PDI/touchdown, surface operations, ascent, rendezvous, and docking intervals.
- **Note:** Use the underlying final flight plan as authority for implementation.

### Apollo 11 press/media resource index

- **Source:** NASA
- **URL:** https://www.nasa.gov/specials/apollo50th/press.html
- **Status:** IDENTIFIED
- **Use:** Discovery index for Apollo 11 press kit, flight plan, mission report, flight journals, audio, imagery, and other mission resources.
- **Note:** Discovery source rather than preferred implementation citation when the underlying document exists.
