# Apollo 11 descent voice source-catalog addendum — note 803

Date: 2026-09-24

| Source | Class | Use / restriction |
| --- | --- | --- |
| NASA History, *News & Notes* 35(3), Apollo 11 Historical Recorder #1 track sheet | Primary/archival configuration image | Establishes recorder channels: IRIG-B GMT ch.1; FLIGHT L/R 7/8; CAPCOM L/R 14/15; GUIDO L/R 21/22. Does not define L/R console function. |
| NASA ALSJ, *Apollo 11 Mission Audio* | NASA provenance statement / historical audio access | Documents JSC Audio Control Room digitization provenance for mission audio except LM onboard. Does not guarantee that every derived web presentation preserves native channel/timing metadata. |
| NASA/JSC `792-AAI` | Primary historical audio | Flight Director-loop target for descent. Catalog time 1955–2025 must not be equated to GET without clock reconciliation. |

## Catalog consequence

Audio evidence now requires explicit fields for artifact, recorder/station channel, source clock, derived GET (if any), and derivation method. A station-channel label is not sufficient evidence for speaker attribution.
