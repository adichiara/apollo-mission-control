# Research note 226 — LMS Mission Effects Projector program-review lead

Date: 2026-09-17
Status: **primary index recovery; underlying report not yet recovered**

## Question

Can the next unresolved LMS-output/acceptance retrieval be narrowed using primary-source catalog evidence adjacent to the already identified `LMA-790-2-LMS` Section 7 output-table accession?

## Primary-source result

The NASA/MSC *Apollo Engineering and Technology Index*, Volume I, Corporate Author Index places the following two Grumman records in the same `NAS9-1100` sequence:

- `LLR-400-329` — 06-07-67 — MSC accession `*67-15490` — `NAS9-1100` — **CONTRACT NAS9-1100, LMS MISSION EFFECTS PROJECTOR PROGRAM REVIEW**.
- `LMA-790-2-LMS` — 01-07-67 — MSC accession `*67-16127` — `NAS9-1100` — **LM MISSION SIMULATOR INSTRUCTORS HANDBOOK, VOL. 2-SIMULATOR OPERATION, SECTION 7-SIMULATOR OUTPUT TABLES**.

Primary index scan:
https://www.ibiblio.org/apollo/NARASWoverflow/CorporateIndex.pdf

## What this establishes

The index establishes a specific, independently accessioned LMS document concerning the **Mission Effects Projector**, issued in the same 1967 period and under the same `NAS9-1100` contract family as the Section 7 output tables. It gives a concrete archival retrieval key: `LLR-400-329` / `*67-15490`.

## What it does not establish

Do **not** infer from the title/index entry alone:

- what variables or displays the Mission Effects Projector accepted or produced;
- that it generated any particular Section 7 output;
- any engineering units, cadence, precision, tolerances, failure modes, or acceptance criteria;
- any controller/station routing;
- any Apollo 13 effectivity or 1970 LMS configuration.

The underlying report has not been recovered in this pass. Web searches on the report number, accession, title, and contract returned the corporate index but no direct report copy.

## Retrieval consequence

Add `LLR-400-329` / MSC `*67-15490` to the high-priority archival request alongside `LMA-790-2-LMS` Section 7 / `*67-16127` and RG 255 E.155B1 acceptance material. If recovered, compare only explicitly documented projector inputs/outputs against Section 7 and acceptance/correlation records; do not bridge them by name similarity.
