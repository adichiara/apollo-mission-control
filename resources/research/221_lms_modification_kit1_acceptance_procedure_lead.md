# Research note 221 — LMS Modification Kit No. 1 acceptance-procedure lead

Date: 2026-09-16  
Status: **DOCUMENT IDENTITY LEAD RECOVERED FROM SECONDARY CATALOG; technical contents not reviewed.**

## Question

Can the unresolved LMS validation/correlation target be narrowed beyond the RG 255 E.155B1 series-level description while preserving the primary-source-first evidence rule?

## Search result

Primary-source searches were run first against NASA/NARA-accessible material and the known Grumman LMS document family. No digitized primary copy of the acceptance procedure was recovered in this pass.

A current Heritage Auctions catalog entry exposes a specific surviving contractor-document lead:

- title: *Apollo Lunar Module Simulator (LMS) Acceptance Test Procedures for Modification Kit No. 1*;
- contractor: General Precision Incorporated, Link Group, Systems Division;
- date: **5 April 1967**;
- report number: **1L5-102-(H)**;
- prepared for Grumman Aircraft Engineering Corporation;
- title-page statement reported by the catalog: prepared/issued in compliance with **P.O. 2-24481C, Section E, Paragraph 5**.

Catalog record:
https://historical.ha.com/itm/space-exploration/miscellaneous/apollo-lunar-module-simulator-lms-acceptance-test-procedures-for-modification-kit-no-1-general-precision-incorporated-lin/a/33174-71524.s

## Evidence classification

This is **not yet primary technical evidence**. The catalog describes an original contractor manual, but the project has not inspected the manual itself. Therefore only the document-identity/retrieval lead is admitted.

The NASA/NARA RG 255 preliminary inventory remains the stronger primary archival evidence for the later LMS acceptance-document family: series E.155B1 (1968–1970) explicitly contains LMS acceptance test plans and procedures. The newly identified 1967 report predates that series date range and must not be assumed to be contained in E.155B1.

Primary inventory:
https://www.ibiblio.org/apollo/NARA-SW/Rg255-1.pdf

## What is established

- A specific, apparently surviving LMS acceptance-procedure document is identifiable by report number `1L5-102-(H)` and date 5 April 1967.
- The lead names General Precision/Link and Grumman, giving a concrete contractor-document retrieval path complementary to RG 255 E.155B1.
- Formal LMS acceptance documentation existed at least as a contractor-document class before the 1968–1970 E.155B1 project-file interval.

## What is not established

Do **not** infer from the catalog:

- any numerical acceptance tolerance;
- any simulator output identifier or observable;
- any subsystem/model correlation criterion;
- test setup, sampling cadence, precision, pass/fail logic, or instrumentation;
- applicability to the final MSC/KSC LMS configuration or Apollo 13;
- that Modification Kit No. 1 corresponds to a particular mission-era software/model revision;
- that `1L5-102-(H)` is present in RG 255 E.155B1.

## Project consequence

The validation-document search now has two concrete retrieval tracks:

1. **Primary archival track:** RG 255 E.155B1 acceptance test plans/procedures and technical reports (1968–1970).
2. **Named contractor-document track:** locate and inspect `1L5-102-(H)` directly, then extract only explicit test observables, criteria, tolerances, model/configuration effectivity, and revision data.

If the contractor manual becomes directly viewable, compare its tested observables against LMA-790-2-LMS Volume II Section 7 only after both documents are inspected. No crosswalk is to be invented from titles alone.
