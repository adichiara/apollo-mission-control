## What this closes

The MEP is no longer represented only by broad archival-series descriptions or later Kollsman-era material. There is now an exact contemporaneous Grumman document target: `LLR-400-329` / MSC `67-15490`.

## What this does not close

The catalog record does **not** expose the program-review contents. Do not infer from the title alone:

- projector hardware architecture;
- scene-generation equations or update cadence;
- computer/DDP-224 ownership;
- EVDE relationship;
- acceptance criteria or tolerances;
- MSC versus KSC installation details;
- Apollo 13 effectivity;
- any relationship between this 1967 `NAS9-1100` review and later Kollsman `NAS9-8634` scope.

## Consequence

Add `LLR-400-329` / `67-15490` as a high-value direct retrieval target alongside `LMA-790-2-LMS`. If recovered, inspect its title/revision pages first, then extract only explicit MEP architecture, interface, configuration, acceptance, and site-effectivity claims.
