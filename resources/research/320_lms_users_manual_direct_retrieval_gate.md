# Research note 320 — LMS User's Manual direct-retrieval gate

Date: 2026-09-18

## Question

Can the 1971 `LMS_Users_Manual.pdf` now be used for machine/program/loading claims, or is it still only a source lead pending page extraction?

## Direct-source result

The public scan is directly indexed at:

https://www.ibiblio.org/apollo/Documents/LMS_Users_Manual.pdf

Its indexed first-page text identifies:

- **UPDATE #34**;
- **October 22, 1971**;
- **LMS USER'S MANUAL**;
- **VOLUME 1**.

The ibiblio/Virtual AGC document index independently lists the object as `LMS_Users_Manual.pdf`, approximately 89 MB.

The current retrieval path cannot open the full 92.8 MB PDF for page-level extraction. Targeted full-document searches for `DDP`, `computer`, and `program` do not return reliable page text through that path. Therefore the manual is **not** promoted here to evidence for machine allocation, program ownership, loading procedure, common-memory mapping, or peripheral routing.

## Evidence boundary

The scan itself is primary historical material, but only the directly indexed cover metadata is page-visible in this pass. Search-engine snippets and prior indexed peripheral-code leads remain retrieval aids, not substitutes for reading the relevant manual pages.

The 22 October 1971 issue is also later than Apollo 13. Even after extraction, any operational-computing fact must be profile-dated and cross-checked against Apollo 13-period configuration/change evidence before historical-profile use.

## Retrieval consequence

The next useful action is a large-file-capable extraction of the manual, preferably preserving page numbers. Search in this order:

1. program loading / load / initialization / initialize;
2. DDP-224 / DDP / computer / processor / machine;
3. common memory / shared memory;
4. magnetic tape / card / typewriter / peripheral / device code;
5. program names and computer-to-program assignments.

Any recovered claim should record exact page, wording, date/effectivity, and whether it describes operator procedure, hardware capability, or actual configuration.

## Result

No station maturity, processor assignment, causal-engine constant, or executable behavior changes. The 1971 manual remains a high-value mature-LMS operational source with a now-explicit direct-retrieval gate.
