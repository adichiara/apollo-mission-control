# Research note 236 — RG 255 E.155B1 current access route

Date: 2026-09-17  
Status: **ACCESS / RETRIEVAL ROUTE RESOLVED; technical records not yet reviewed**

## Question

The project already has a precise legacy locator for the LMS project files — RG 255 series E.155B1, old accession `72A794`, location `A-23-16-6`. What is the current NARA route for turning that locator into an actual research request without pretending the records are publicly digitized?

## Primary archival identity

The NASA/JSC RG 255 preliminary inventory describes:

**E.155B1. Project Files on the Lunar Module Simulator, 1968–1970, 2 ft.**

The series is arranged by subject and includes:

- correspondence and memoranda;
- statement of work;
- program and procurement plans;
- acceptance test plans and procedures;
- progress and technical reports;
- operations manuals;
- photographs of surface models;
- copies of drawings.

It states that most correspondence is with Kollsman Instrument Corporation and concerns administration of contract `NAS9-8634` for construction of LM simulators at MSC and KSC. The inventory gives old accession `72A794` and legacy location `A-23-16-6`.

Primary inventory:
https://www.ibiblio.org/apollo/NARA-SW/Rg255-1.pdf

## Recommended request packet

A reference request should include all of the following rather than relying on a generic “Lunar Module Simulator” search:

- Record Group: **RG 255 — Records of the National Aeronautics and Space Administration**;
- series: **E.155B1 — Project Files on the Lunar Module Simulator, 1968–1970**;
- old accession: **72A794**;
- legacy location: **A-23-16-6**;
- contract key: **NAS9-8634**;
- contractor key: **Kollsman Instrument Corporation**;
- priority document classes:
  1. statement of work;
  2. acceptance test plans;
  3. acceptance test procedures;
  4. progress and technical reports;
  5. procurement/program plans;
  6. operations manuals;
  7. drawings and surface-model photographs;
  8. correspondence that identifies dated simulator configuration/effectivity.

The first request should ask NARA staff to confirm the current physical/archival location and available container/folder list before assuming that the preliminary inventory's legacy location maps directly to a present shelf location.

## Evidence boundary

This note resolves **how to request the records**, not what they contain beyond the series description.

Do not infer:

- that E.155B1 is digitized;
- current box/folder numbers from the old `A-23-16-6` locator;
- that all documents in the series concern the same simulator configuration;
- that `NAS9-8634` subsumes every LMS subsystem;
- any acceptance tolerance, numerical criterion, output variable, update rate, or Apollo 13 effectivity until the records are inspected.

## Project consequence

The RG 255 acceptance-document workstream is no longer merely “search NARA.” It has a concrete current consultation path and a complete request identifier set.

Once records are obtained, extraction should follow the validation evidence model already adopted in the repository:

`document/revision → simulator configuration/effectivity → source/model → stimulus → observable → units → criterion/tolerance → result/correlation evidence`

The highest-value first pass remains the statement of work plus acceptance plans/procedures because those can define what was actually subject to acceptance before detailed reports are interpreted.
