# Station research-status addendum — low-player-count aggregation

Date: 2026-09-12  
Parent: `docs/STATION_RESEARCH_STATUS.md`

## Overall

Historical station maturity grades do not change. This pass addresses player assignment, not new console/display evidence.

Apollo 13 primary sources support functional group relationships but do not show the project’s proposed bundled-player configuration as historical manning.

## FLIGHT

**Maturity unchanged.**

Compact-mode rule: remains an independent player role. Do not combine final FLIGHT authority with a technical station in the recommended compact configuration.

## CAPCOM

**Maturity unchanged.**

Compact-mode rule: remains an independent player role. CAPCOM’s crew-voice function stays distinct from INCO’s communications-engineering function.

## TELMU + CONTROL

**Maturity unchanged.**

Project compact bundle: `LM SYSTEMS`.

The player may receive both station presentations, but:

- TELMU and CONTROL retain separate data ownership;
- actions retain original station authorization;
- readiness remains attributable to the original station;
- audit entries retain original station identity.

No claim is made that one Apollo 13 controller historically performed both positions during PC+2.

## GUIDO + FIDO/RETRO

**Maturity unchanged.**

Project compact bundle: `FLIGHT DYNAMICS`.

The grouping is constrained by Apollo’s Flight Dynamics organization, but the one-player bundle is a project simplification. Guidance-computer/navigation-state responsibilities must remain distinguishable from trajectory/return-plan responsibilities.

## INCO

**Maturity unchanged.**

Remains independent in the recommended five-player compact mode. Apollo evidence distinguishes INCO technical communications responsibilities from CAPCOM crew voice.

## Historical sharing evidence

Apollo 13 Review Board material records INCO and O&P sharing a console/responsibility. This demonstrates that selected functional sharing existed historically, but it is not generalized into evidence for arbitrary station combinations.

## Result

Recommended compact player count for the current PC+2 slice: **5**.

Four-player-or-smaller aggregation remains unresolved.
