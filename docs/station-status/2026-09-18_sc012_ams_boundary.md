# Station-status addendum — SC-012 AMS evidence boundary

Date: 2026-09-18  
Parent: `docs/STATION_RESEARCH_STATUS.md`

Historical Apollo 13 station maturity grades remain unchanged.

The newly public SC-012 Apollo Mission Simulator handbook family is now source-controlled as **15 April 1966 AS-204A / Block I Command Module simulator material**. It may provide comparative evidence about how an Apollo simulator exposed instructor, malfunction, and output concepts, but it does **not** establish Apollo 13 LM LMS outputs, MCC routing, station display content, telemetry loading, or instructor failure controls.

Accordingly, no CONTROL, TELMU, GUIDO, FIDO/RETRO, INCO, FLIGHT, CAPCOM, or EECOM station claim is upgraded from this source family. Any later use must be explicitly labeled comparative/adjacent unless corroborated by LMS- and mission-effective evidence.
