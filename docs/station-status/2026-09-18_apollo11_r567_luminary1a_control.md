Date: 2026-09-18

**DOCUMENTED:** the Luminary 99/1 assembly listing identifies the program as LUMINARY 1A and points to `R-567, as amended` for implementation details.

**PARTIALLY DOCUMENTED:** R-567 is now a controlled Apollo 11-era source family for the current guidance/interface investigation, but only Section 2 Rev. 4 has been directly controlled in this pass.

**UNRESOLVED:** the Apollo 11-effective Section 5 Guidance Equations revision/change state; exact landing-radar geometry/update equations; estimator/filter equations; powered-descent guidance equations/constants; and the technical deltas represented by the named PCR/PCN entries.
