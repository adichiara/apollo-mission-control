# Station-status boundary — Kollsman KSC LMS AOT provenance

Date: 2026-09-17

Status: **simulator component provenance strengthened; Mission Control station status unchanged**

The Smithsonian now provides object-level provenance for a Kollsman-manufactured Alignment Optical Telescope that was part of the KSC Lunar Module Simulator used for astronaut mission training.

This concerns simulator crew-compartment hardware. It supplies no evidence for a Mission Control console assignment, controller display, telemetry path, Section 7 output mapping, or station procedure. No station claim changes.

Do not infer Apollo 13 effectivity or `NAS9-8634` procurement scope from the object record. Those remain archival retrieval questions.
