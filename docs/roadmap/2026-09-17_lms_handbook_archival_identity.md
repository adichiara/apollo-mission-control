# Roadmap update — LMS handbook archival identity

Date: 2026-09-17

## Current state

Research notes 235, 236, 238, and 239–243 constrain both LMS compute-topology evidence and the next primary retrieval path.

The mature LMS is supported as a three-machine complex with one machine dedicated to onboard-guidance-computer simulation. The original two machine workloads remain unknown. Exact NASA/MSC accession keys are now known for the 1967 Grumman LMS instructor handbook and for a contemporaneous LMS Mission Effects Projector program review.

NASA/KSC GP-642 maps the exact Volume I title to GAEC `LMA 790-2-LMS`, dated Apr. 1, 1967. A public digitized Volume I title-match candidate is known, but its identity as the particular `67-14186` accession copy is not yet proven from the scan itself.

NASA/MSC corporate-author control separately identifies Grumman `LLR-400-329`, *Contract NAS9-1100, LMS Mission Effects Projector Program Review*, dated 06-07-67, accession `67-15490`. Its contents have not yet been recovered.

NASA NTRS `19690026999`, Aero Service's primary July 1969 *Final Report — LEM Mission Simulator Film Graphics* (`NAS 9-5981`), now directly establishes a terrestrial/lunar film-graphics production path for MEP use, NASA/Grumman/Farrand coordination, and late-1967 Lunar-Orbiter-driven lunar-detail enhancement. It does not establish projector hardware architecture or vendor succession. NASA SP-4009 identifies a specific 30 Aug. 1967 Bethpage weekly report as the underlying record for the Farrand specification problem and proposed Itek study; retrieve that report before treating the sequence as primary-source closed.

## Priority retrieval sequence

1. **Digitized Volume I identity gate** — inspect the candidate scan's title/revision pages.
2. **`67-14186` body** — if identity closes, search for DDP-224 roles, interfaces, program allocation, digital conversion, guidance-computer simulation, and common-memory architecture.
3. **`67-15490` / `LLR-400-329`** — retrieve the Grumman LMS Mission Effects Projector program review; inspect for explicit MEP architecture, interfaces, computer ownership, EVDE relationship, acceptance/configuration data, and site effectivity.
4. **Bethpage weekly report, 30 Aug. 1967** — recover `MSC, BMR Bethpage, Weekly Activities Report, Week Ending August 25, 1967` to resolve the Farrand specification problem / proposed Itek study at primary-source level.
5. **`67-16127`** — Volume II, Section 7, Simulator Output Tables.
6. **`67-14187` / `67-14188`** — Volume II operating sections if machine/program allocation remains unresolved.
7. **RG 255 E.155B1 / program-loading records** — pursue date/site effectivity and later configuration changes, including Kollsman `NAS9-8634`.
8. **Apollo 13-period configuration records** — only after generic/deployed architecture is bounded.

## Metadata caution

Do not silently reconcile the `67-14186`/`67-14187` date discrepancy. The MSC main index and KSC GP-642 support 01-04-67; the MSC supplement gives 15-05-67.

## Gate

Bibliographic titles establish retrieval identity, not technical content. Film-graphics evidence establishes MEP content-production support, not projector architecture or vendor succession. Do not assign the original two computers, MEP/EVDE architecture, causal domains, station products, cadence, acceptance tolerances, or a Farrand→Itek→Kollsman chain without opened technical/configuration records. Close model inputs only from adequate source evidence or under D-022 demonstrated irrelevance.
