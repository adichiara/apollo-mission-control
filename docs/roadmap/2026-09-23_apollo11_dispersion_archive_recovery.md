## New primary-archive finding

The official Purdue University Archives catalog gives an exact physical and hierarchical locator for the **2 July 1969 addendum** to Internal Note **69-FM-156**, *Apollo 11 (Mission G) Spacecraft Dispersion Analysis, Vol. IV, Descent and Ascent Dispersion Analyses, Part 1 Lunar Descent*: **Box 55, Folder 2, Item 5**; identifier **MSA 5, Series 1, Sub-Series 5, Sub-Group 4, File 3, Item 10**.

This materially narrows recovery of one of the two known 69-FM-156 source states. It does **not** recover the underlying pages and does not establish that the 10 June 1969 base analysis and 2 July addendum are textually identical.

The same official archive independently holds **Internal Note 69-FM-20, Preliminary Lunar Descent Dispersion Analysis**, in two Armstrong-file contexts: **Box 39, Folder 1, Item 3** (identifier `MSA 5, Series 1, Sub-Series 5, Sub-Group 2, File 12, Item 3`) and **Box 48, Folder 10, Item 1** (identifier `MSA 5, Series 1, Sub-Series 5, Sub-Group 3, File 7, Item 88`). These are useful precursor recovery targets, but no assumption is made that the two holdings differ or that either supplies the later Mission-G numerical inputs.
