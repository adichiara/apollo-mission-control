# Roadmap addendum — RG 255 LMS visual-system retrieval

Date: 2026-09-17

## Newly resolved

The primary RG 255 inventory identifies E.155B as a location containing MEP/EVDE material and E.155B1 as a later 1968–1970 dedicated LMS project-file series with Kollsman / `NAS9-8634` retrieval keys.

Primary NASA/Kollsman final-report records establish a separate contract identity for the Apollo Optical Subsystem and LM Alignment Optical Telescope program: **NAS9-497**. The KSC LMS AOT provenance therefore must not be used by itself to assign that hardware to `NAS9-8634`.

Research note 232 tested public primary-source discovery for exact/variant `NAS9-8634` forms with Kollsman/LMS/MSC/KSC. No digitized contract, statement of work, acceptance procedure, or technical report exposing subsystem scope was recovered.

Research note 233 establishes from the primary RG 255 inventory that the E.155B1 Kollsman correspondence concerns administration of **`NAS9-8634` for construction of LM simulators at both MSC and KSC**. Deliverables, subsystem responsibility, configuration, and effectivity remain unresolved.

Research note 234 clarifies provenance: **E.155B is the 20-foot Reference Files on the Lunar Landing Training Vehicle series**, whose description says it also contains some LMS MEP/EVDE material. E.155B1, by contrast, is explicitly the dedicated *Project Files on the Lunar Module Simulator*. Treat E.155B as a narrow MEP/EVDE subset-retrieval target, not as an LMS visual-system collection.

Research note 236 now resolves the current NARA access route for E.155B1. A Textual Reference request to `archives2reference@nara.gov` should supply the complete identifier set **RG 255 / E.155B1 / old accession 72A794 / legacy location A-23-16-6 / NAS9-8634 / Kollsman** and ask staff to confirm present container/folder and physical-location information before assuming the legacy locator is a current shelf address.

## Still unresolved

The relationship among the 1967 Farrand MEP, the E.155B MEP/EVDE records, Kollsman's `NAS9-8634` work, and the Apollo 13-era LMS configuration is not established. Whether `NAS9-8634` included AOT support or other optical work also remains unresolved.

Formal LMS acceptance criteria remain unrecovered. The current access-route work does not authorize numerical acceptance tolerances, output variables, update rates, or Apollo 13 effectivity.

## Next sequence

1. Submit/prepare the E.155B1 reference request using **RG 255 / E.155B1 / 72A794 / A-23-16-6 / NAS9-8634 / Kollsman**, prioritizing statement of work and program records, then acceptance plans/procedures, drawings, surface-model photographs, and correspondence. Ask for the current container/folder list first.
2. Retrieve the **MEP/EVDE subset within E.155B**, narrowly keyed to `Mission Effects Projector`, `MEP`, `External Visual Display Equipment`, `EVDE`, and `Lunar Module mission simulator`, using old accessions `72A797` / `73ABC1675` and the inventory locations. Do not treat surrounding LLTV/LLRV files as LMS evidence.
3. Keep `NAS9-497` AOT/optical-subsystem and `NAS9-8634` LMS records as separate contract trails unless explicit primary text connects them.
4. Build a dated vendor/configuration matrix only from explicit document statements.
5. Crosswalk recovered records against `LLR-400-329` / `*67-15490` and Section 7 / `*67-16127`.
6. Do not infer Mission Control routing or Apollo 13 effectivity until directly supported.
