## D-022 candidate boundary

The obvious PC+2 mass pair is not yet accepted as a D-022 range:

- final P30 module-weight sum: `95,932 lb`;
- postflight reconstructed PC+2 ignition event mass: `95,424.0 lb`.

Research notes 147–148 explicitly classify these as different historical product classes. No recovered source establishes them as bounds on the same physical/model input. Treating them as a range without that bridge would collapse the unresolved mass-accounting mechanism and violate D-022.

The next D-022 task is therefore to identify a model input with a genuinely sourced plausible range, then run the endpoint sensitivity against controller-visible products at documented resolution. If no such range is yet supported for the highest-priority PC+2 gate, archival work remains justified.
