## Primary-source result

Philco-Ford **PHO-TR474** identifies **Mission H-2 Telemetry Data Format Control Book (TDFCB), Revision 4** as a mission-specific telemetry configuration baseline.

The report states that H-2 Rev. 4 was delivered on **28 January 1970** and included master/tape copies, high-speed and wideband requirements, a **special LM Flight Control listing**, Flight Control listing/compare, index listing, and master compare. Philco also reports checking all required LM measurements for processing problems, checking the **H-2 Rev. 4 TDFCB PCMGS against PHO-TR155 on 10 February**, checking the MCC Master Measurement Number List against H-2 Rev. 4, and preparing an H-2/H-3 Format-30 comparison in March.

## Interpretation

This establishes a second mission-specific configuration authority alongside PHO-TR155:

- **TDFCB Rev. 4:** telemetry measurement/format/Flight Control configuration;
- **PHO-TR155 Rev. C:** MCC operational/display configuration.

The source explicitly documents a cross-check between them. It does not reproduce the H-2 TDFCB listings, so exact `GC0071V` / `GC0155F` membership, sample cadence, routing, and display placement remain unresolved.
