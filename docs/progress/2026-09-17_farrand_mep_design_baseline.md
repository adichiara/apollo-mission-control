# Progress — Farrand MEP design baseline

Date: 2026-09-17

Research note 228 recovered a primary 1964 Farrand/NASA technical description of the Mission Effects Projector: a non-programmed continuous color film-strip projector for Earth-orbital imagery, moving cloud cover, and sunrise/sunset simulation, using two film cassettes for different scales.

This is now documented only as a technology-family baseline. It does not establish the configuration, requirements, Section 7 mapping, station routing, or Apollo 13 effectivity of the 1967 LMS MEP.

Next controlling target remains direct recovery of Grumman `LLR-400-329` / MSC `*67-15490`, with Section 7 / `*67-16127` and LMS acceptance records retained in the retrieval set.
