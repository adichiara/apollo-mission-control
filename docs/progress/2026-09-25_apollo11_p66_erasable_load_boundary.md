# 2026-09-25 — Apollo 11 P66 erasable-load boundary

Research 904 narrows the next Apollo 11 powered-descent numerical dependency. Apollo-11-effective LUMINARY 1A code establishes P66 logic but stores the ROD scale, ROD time constant, lag ratio, and force limits as erasable load values. A surviving 1969 MIT Apollo 11 landing digital simulation provides explicit values for that simulation configuration, including RODSCALE 0.003048 M/CS, TAUROD 150 CS, and LAG/TAU 0.413333.

Implementation consequence: these values may support a labeled simulation-load validation profile, but they are not yet admissible as LM-5 as-flown pad loads. The active retrieval target is now mission-effectivity evidence for the P66 erasables, separately from the already blocked LM-5 continuous DPS calibration.
